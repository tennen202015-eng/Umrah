# رفيق العمرة — تطبيق أندرويد

تطبيق بيعدّ أشواط الطواف والسعي لوحده. بيعتمد على الـ GPS مع الجيروسكوب وعدّاد الخطوات، وبيشتغل من غير إنترنت. مبني بـ Capacitor من نفس صفحة الويب.

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `src/app.html` | التطبيق نفسه (نفس نسخة الويب) |
| `capacitor.config.json` | اسم التطبيق ومعرّفه `com.umrah.companion` |
| `android-res/` | الأيقونة وشاشة البداية |
| `scripts/build-web.js` | بينسخ التطبيق والخطوط علشان يشتغل من غير إنترنت |
| `scripts/patch-android.js` | بيركّب الأيقونات، ويضيف صلاحية الموقع والاهتزاز، ويثبّت الشاشة عمودي، ويخليها منوّرة طول ما التطبيق مفتوح |
| `.github/workflows/android.yml` | بيبني ملف APK على GitHub لوحده |

## بناء APK على GitHub

1. ارفع ملفات المشروع كلها على مستودع جديد في GitHub، ومعاهم فولدر `.github`.
2. من تبويب **Actions** هتلاقي **Build Android APK** شغال. البناء بياخد حوالي ٥-٨ دقايق.
3. لما يخلص افتح الـ run، ومن **Artifacts** نزّل `umrah-companion-apk`.
4. انقل `app-debug.apk` للجوال وسطّبه، واسمح بالتسطيب من مصادر غير معروفة.

## على الكمبيوتر بـ Android Studio

```bash
npm install --legacy-peer-deps
npm run build:web
npm run android:init
npx cap sync android
npx cap open android
```

## الصلاحيات

- **الموقع الدقيق:** بيتطلب مرة واحدة أول ما تضغط «تشغيل التتبع». لو اخترت «الموقع التقريبي» العدّ بالـ GPS مش هيشتغل.
- **الاهتزاز وإبقاء الشاشة منوّرة:** صلاحيات تلقائية، مابتظهرش للمستخدم.
- **الحساسات (الجيروسكوب والتسارع):** مش محتاجة إذن في أندرويد.
- **ممنوعة صراحةً في الملف:** الكاميرا، والميكروفون، والصور، والملفات، وجهات الاتصال، والموقع في الخلفية.

## الاستخدام في الحرم

- اضغط **تشغيل التتبع** قبل ما تدخل المطاف، وسيب التطبيق مفتوح.
- **وضع الجيب** بيحوّل الشاشة لأسود (بيوفّر البطارية في شاشات OLED) وبيمنع اللمس بالغلط. العدّ والتنبيه بالصوت والاهتزاز بيكملوا، وعشان تخرج منه اضغط مطولاً.
- لو قفلت الشاشة بزرار الباور أو فتحت تطبيق تاني، التتبع بيقف لحد ما ترجع. ده حدود النسخة دي.
- الصوت بيستخدم محرك النطق العربي بتاع الجوال. لو مش متسطّب نزّل «Speech Services by Google» وفعّل العربي.
